# AI-Document-Chatbot-using-RAG
Built an AI-powered chatbot that allows users to upload PDF documents and ask questions using Retrieval-Augmented Generation (RAG). Integrated Hugging Face embeddings, ChromaDB for semantic search, and Groq LLM for context-aware responses with source references. Tech Stack: Python, LangChain, RAG, Hugging Face, ChromaDB, Groq API, Streamlit.
